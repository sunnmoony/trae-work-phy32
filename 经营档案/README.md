# 经营档案

本目录存放流水线各节点的数据资产（按设计文档第 7 章）。《经营手册》为知识库，位于 `/workspace/经营手册.md`（不在本目录）。

| 文件 | 归属 | 说明 |
|------|------|------|
| 经营仪表盘.md | S0 | 每日 1 行，周汇总 |
| 候选清单.md | S1 | 商品/趋势/可模仿性/毛利/合规/建议动作 |
| 每日情报日报.md | S1 | 每日拉榜存档（含平台前瞻信号） |
| 前瞻信号.md | S1 | 平台新内容形态/规则变化观察 |
| 竞品拆解笔记.md | S1 | 六维拆解存档 |
| 上架卡-<SKU>.md | S2 | 每 SKU 1 份 |
| 货架运营日志.md | S3 | SKU/曝光/点击/转化/优化动作 |
| 周内容计划.md | S4 | 5 条排期 + 发布记录 |
| 达人效果档案库.md | S5 | 达人/GMV/退货率/ROI/续约决策 |
| 周复盘.md / 月复盘.md | S6 | 漏斗/命中率/规则修订 |

规则：每个文件头部注明数据口径与更新时间；复盘修订规则时同步 bump 版本号。
