## 2. 脚本速览（本周 7 条）

**#1 菊花茶·引流（25s）**
- 钩子：菊花茶天天喝，这3类人反而越喝越不舒服，看看有没有你
- 内容：倒料展示朵型 → 脾胃虚寒、腹泻期、孕早期少喝 → +枸杞、+金银花搭配
- 结尾：先收藏，下次照着泡｜标签：#菊花茶 #胎菊王 #护眼茶 #办公室养生茶

**#8 茯苓红豆薏米茶·主力（30s）**
- 钩子：总犯困、没精神？老一辈常喝的食养搭配
- 内容：茯苓丁/薏米/赤小豆倒料 → 独立小袋展示 → 85℃冲泡谷物香
- 结尾：先收藏｜标签：#茯苓茶 #红豆薏米茶 #上班族养生

**#3 金银花茶·引流（25s）**
- 钩子：家里常备金银花，但你泡对了吗
- 内容：金银花偏寒别天天喝；嗓子干痒时再喝 → +山楂、+菊花两种搭配
- 结尾：苦就加罗汉果，先收藏｜标签：#金银花茶 #嗓子不舒服 #养生花茶

**#11 陈皮茶·知识型（收藏型，30s）**
- 钩子：同样是陈皮，有的3块有的30块，区别在哪
- 内容：看油室（小点越密香气越足）→ 陈皮丝倒料冲泡 → 3年以上才够味
- 结尾：先收藏，照着挑｜标签：#陈皮茶 #陈皮丝 #解腻茶

**#2 菊花茶·场景（25s）**
- 钩子：每天盯屏幕8小时，下午两点准时困？试试这杯
- 内容：菊花+枸杞倒料 → 85℃冲泡 → 汤色展示
- 结尾：独立小袋随手泡，先收藏｜标签：#菊花枸杞茶 #护眼茶 #上班族养生

**#9 茯苓对比（收藏型，30s）**
- 钩子：同样是红豆薏米茶，价格差10倍，差在哪
- 内容：先看配料表：茯苓、薏米、赤小豆排前面才靠谱 → 少买加糖加香精的
- 结尾：先收藏，买前对照｜标签：#红豆薏米茶 #茯苓薏米茶 #配料表

**#20 质检信任·打底（30s）**
- 钩子：买养生茶最怕什么？怕小作坊、怕没资质、怕混料
- 内容：SC证特写 → CMA质检报告 → 原料仓库实拍 → 分装车间
- 结尾：先收藏，关注看更多原料实拍｜标签：#代用茶 #食品安全 #源头工厂

## 3. 拍摄执行（1-2 天集中拍完）

- 设备：手机竖屏 4K、领夹麦、补光灯+窗边自然光、俯拍支架
- **一条布景连拍多条**：固定「倒料特写位 → 冲泡位 → 手持口播位」三机位
- 布景：白瓷碗×2、透明玻璃杯×3、木勺、托盘；每 SKU 备 2 份（一份倒料、一份冲泡）
- 素材补充：拍 #20 时一并拍 SC 证/质检报告/仓库（信任背书素材库）
- 合规红线：口播/字幕禁「治疗、疗效、祛湿、降火、补血、降血糖、抗癌」
