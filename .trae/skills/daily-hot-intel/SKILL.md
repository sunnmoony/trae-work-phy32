# 每日热卖情报监控（Daily Hot Intel）

借鉴社区 douyin-hot-trend「每日抓取 + 结构化日报」机制，但数据源全部换成**已授权的安全数据源**，不抓取抖音页面、不依赖第三方聚合 API。

## 目的

每天 3 分钟内产出一份「热卖情报日报」，回答三个问题：
1. 今天抖音养生茶/药食同源赛道什么在爆？
2. 价格带和形态有什么变化？
3. 我们（10 SKU 货盘）今天该做什么调整？

## 数据源（按优先级）

| 优先级 | 数据源 | 用途 |
|--------|--------|------|
| 1 | 灰豚 ht-api-trae（MCP，已授权） | 抖音商品热销榜/达人榜/直播榜查询 |
| 2 | WebSearch | 新趋势、新规、行业新闻补充 |
| 3 | 巨量算数（官网） | 核心词热度验证 |
| 4 | 抖店罗盘（后台） | 自家商品昨日数据 |

## 执行流程（每日例行）

1. **拉榜**：用灰豚按核心词查询热销商品（核心词池：红豆薏米、茯苓、菊花、金银花、黄芪、苹果、桂圆红枣、陈皮、麦冬、蒲公英）
2. **记录**：商品名 / 店铺 / 销量区间 / 价格带 / 近期涨幅 / 商品形态（袋装/瓶装/独立小袋）
3. **补充**：WebSearch 当日养生茶相关新闻（新规、曝光事件、流行趋势）
4. **比对**：与自家货盘（商品价目总表 + 赛马执行表）逐项比对 → 输出行动建议
5. **存档**：日报追加到 `每日情报日报.md`（若已存在），今日无变化则只更新日期行

## 输出模板（日报）

```markdown
# 抖音养生茶热卖情报日报（YYYY-MM-DD）

## 今日爆款 TOP5
| 商品 | 店铺 | 销量 | 价格带 | 形态 | 说明 |
|------|------|------|--------|------|------|

## 新上榜 / 涨幅榜
（重点记录新出现的高增速商品）

## 趋势信号
- 价格带：…
- 形态变化：…
- 合规新动态：…

## 对本店 3 条行动建议
1. …
2. …
3. …
```

## 规则

- 每天一次，3 分钟内完成；每周日额外输出周报（本周爆款回顾 + 下周边铺货预判）
- **只读情报**：不直接改价/上架，调整动作需用户确认
- 记录时保留「销量区间」而非精确值（第三方数据有误差，注明口径）
- 发现新爆款但自家无货 → 记入「潜在补货清单」，标注进价待核实
