# 每日热卖情报监控（Daily Hot Intel）

借鉴社区 douyin-hot-trend「每日抓取 + 结构化日报」机制，数据源全部用**已授权安全源**（灰豚/蝉妈妈/搜索/罗盘），不抓抖音页面、不用第三方聚合 API。

## 0. 适用与触发

- 每日例行：用户要求"看看今天有什么爆款/热卖/新趋势"
- 铺货调整前：需基于最新行情改货盘
- 每周日自动升级为周报

## 1. 输入校验（门禁 G0）

必填：核心词池（默认从打法文档 6.1 词库取，可覆盖）
校验规则：
- 词池 ≥3 个词，否则拒绝执行并提示补词
- 每个词需区分「品类词」与「功效词」——功效词（祛湿/降火等）仅用于搜索竞品，**禁止**写入自家商品
缺失处理：无词池 → 拒绝并提示；数据源不可用 → 走 6. 降级路径

## 2. 执行流程（每步含数据质量规则）

**Step 1 拉榜（多源）**
- 主源：灰豚商品热销榜（按核心词）
- 副源：蝉妈妈同款查询 + WebSearch 当日新闻
- 数据质量规则：每个商品记录「销量区间」而非精确值；两源数值偏差 >20% 时取低值并标注"±"

**Step 2 去重与异常值过滤**
- 同一商品多店出现 → 合并记录，标注店铺数
- 销量环比跳变 >300% → 标记"疑似大促/达人带货"，不直接采信为趋势
- 剔除：明显刷单特征（销量高但 0 评论）、已下架链接

**Step 3 趋势判断（环比逻辑）**
- 与昨日/上周同期对比：连续 3 天上升 = 起量信号（标记 🔺）
- 新出现且销量 >500 件 = 新爆款（标记 🆕）
- 连续 3 天下降 >20% = 退潮（标记 🔻）

**Step 4 比对货盘与决策**
- 新爆款 → 货盘有无货？
  - 有 → 行动：A 级加权（标题同步热词、加购促销）
  - 无 → 记入「潜在补货清单」，标注进价待核实
- 自家在售款出现 🔻 → 预警：检查标题/价格/差评，输出 1 条处理建议

**Step 5 存档**
- 日报追加至 `每日情报日报.md`；今日无变化只更新日期行

## 3. 质量门禁

- G1 数据完整性：爆款 TOP5 每行 6 个字段齐全（商品/店铺/销量/价格/形态/说明），缺字段需回填
- G2 情报一致性：三源（灰豚/蝉妈妈/搜索）≥2 源一致才标"确认趋势"，仅单源标"待验证"
- G3 行动可执行：日报结尾必须有 3 条「可执行行动」且每条含对象+动作，否则重写

## 4. 输出自查清单（交付前必过）

- [ ] 无单源数据冒充确认趋势
- [ ] 无功效词写入自家建议（引用竞品时标注"对方违规"）
- [ ] 每条行动含明确对象与动作
- [ ] 数据标注口径与时间

## 5. 执行后复盘（写入执行日志）

每次执行后在 `.trae/skills/daily-hot-intel/exec-log.md` 追加：
- 本次数据源可用性（灰豚/蝉妈妈/搜索各可用否）
- 异常记录（数据跳变/去重误判/词池失效）
- 命中率回顾（周日）：上周日报预判的趋势，实际验证了多少？<60% 触发规则修订
- 规则更新 → 本文件版本号 +1，并在 7. 版本记录登记

## 6. 异常与降级处理

| 异常 | 处理 |
|------|------|
| 灰豚不可用 | 降级为 蝉妈妈 + WebSearch + 罗盘；仍失败 → 纯搜索 |
| 全数据源不可用 | 输出降级日报（仅自家罗盘数据 + "外部趋势未获取"标注），不编造数据 |
| 词池命中 0 结果 | 扩词重跑一次；仍 0 → 标记"本类目今日无新热点"，不硬编 |
