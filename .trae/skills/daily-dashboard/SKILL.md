# 经营仪表盘（S0）

流水线入口。原则：数据机制的核心不是"看"，是"触发"——没超阈值就不动。

## 0. 触发
- 每日例行（建议固定时段，5 分钟）/ 每周一（20 分钟版）

## 1. 输入契约
必填：罗盘/抖店后台数据（曝光/点击率/转化率/GMV/体验分，含口径与日期）
- 数据缺失 → 输出"待补数据"清单，不编造；缺体验分可暂用前日值并标注

## 2. 分级执行

**5 分钟版（每天）：**
1. 记录 5 个数到 `经营档案/经营仪表盘.md`（每日 1 行）
2. 对照阈值表，超阈值的项输出动作（≤3 条）

**20 分钟版（每周一）：**
1. 同上 + 渠道归因（搜索/推荐/商城三段漏斗）
2. 环比上周，输出"本周 3 个焦点"

## 3. 阈值表（初版，S6 复盘可修订）

| 指标 | 阈值 | 触发动作 |
|------|------|---------|
| 曝光 | 0 连续 48h | 修标题/属性（S3） |
| 点击率 | <3% | 修主图（A/B 换图 48h 复测） |
| 转化率 | <1% | 修价格/详情/评价（S3） |
| GMV | 环比 -30% | 预警：查渠道/评价/竞品动作（S1） |
| 体验分 | <4.5 | 排查服务/物流，停售整改 |

## 4. 输出契约
- 每日：`经营档案/经营仪表盘.md` 追加 1 行 + 动作清单（对象+动作）
- 每周一：本周 3 个焦点 → 传给 S1-S5

## 5. 数据回流
- 阈值与实际数据不符（如点击率长期 >5% 仍无单）→ 记入异常 → S6 修订阈值表
