# 竞品爆款拆解（Competitor Teardown）

借鉴蝉妈妈视频拆解 + 灰豚榜单能力，封装为固定调研流程，输出可直接照做的清单。

## 输入

- 对标对象：店铺名 / 商品 / 达人账号（任选其一）
- 可选：拆解目标（货盘 / 内容钩子 / 直播话术 / 信任背书）

## 执行流程

1. **定位**：用灰豚搜索店铺/商品/达人，选定 1-3 个对标对象
2. **拉数据**：销量 / 价格带 / 客单价 / 评分 / 回购率 / 近 30 天趋势
3. **货盘拆解**：引流款（低价走量）/ 利润款 / 形象款 结构，凑单与破价机制
4. **内容拆解**：拉其带货视频，拆前 3 秒钩子、中段展示、结尾转化话术
5. **信任背书拆解**：质检公示 / 源头实拍 / 资质展示 / 特殊人群提示
6. **比对输出**：哪些我们能直接复制，哪些不可复制（资金/粉丝），转化为 3 条可落地行动

## 输出模板

```markdown
# 竞品拆解：{对象名}

## 基础数据
| 指标 | 数值 | 口径 |
|------|------|------|

## 货盘结构
- 引流款：…
- 利润款：…
- 凑单/破价机制：…

## 内容钩子（前3秒）
- 视频1：…
- 视频2：…

## 信任背书
- …

## 可复制清单（我们直接照做）
1. …
2. …

## 不可复制项（标注原因）
- …

## 落地行动 3 条
1. …
2. …
3. …
```

## 规则

- 数据注明口径与时间（灰豚数据为第三方，允许 ±20% 误差）
- 违禁词零容忍：拆解笔记中若引用对方文案含功效词，标注「❌ 对方违规，不可复制」，并给出合规替代表达
- 拆解结果存档到 `竞品拆解笔记.md`
