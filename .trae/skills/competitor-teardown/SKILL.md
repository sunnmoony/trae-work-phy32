# 竞品爆款拆解（Competitor Teardown）

借鉴蝉妈妈视频拆解 + 灰豚榜单能力，封装为「筛选 → 双源核验 → 六维拆解 → 可执行转化」的固定调研流程。

## 0. 适用与触发

- 调研竞品 / 学习爆款打法 / 寻找对标账号 / 拆解带货视频
- 新品立项前 / 引流策略制定前 / 每周例行竞品监控

## 0.5 契约（三合一体系）
- 输入契约：对标对象（对标店铺/爆款商品/达人账号）
- 分级执行：日常 5 分钟版（每周例行竞品监控，快速看对标更新）/ 攻坚 60 分钟版（新品立项前/引流策略制定前六维深拆）
- 输出契约：经营档案/候选清单.md 对标节 → S4
- 数据回流：落地无效果→修筛选

## 1. 输入校验（门禁 G0）

必填（三选一）：对标店铺名 / 爆款商品 / 达人账号
校验规则：
- 输入为商品链接或模糊名称 → 先用灰豚定位 API 精确定位（商品 `product_search` / 店铺 `shop_search` / 达人 `author_search`），定位失败（<2 条结果）→ 拒绝并提示换关键词
- 拆解目标缺失 → 默认全维度（货盘+内容+信任+复购）

## 2. 执行流程

**Step 1 对标筛选（客观评分，每项必须给出量化锚点与数据来源）**

| 维度 | 量化锚点（数据来源） | 5 分标准 |
|------|---------------------|---------|
| 相关性 | 类目/客单与自家对比（`product_basic_info`(pid) 取商品类目与价格） | 同属养生茶/滋补茶类目且客单 ±30% |
| 销量体量 | 月销数据（`product_library_custom_search_product`(keyword=商品名, sortField=sales30, searchType=2) + 蝉妈妈交叉，偏差>20% 取低值） | 月销 ≥1000 |
| 模式相似度 | 是否无自播/货架+内容（`author_commerce_category_list` 看带货品类 + `author_related_video_list_video` 看视频形态） | 货架+内容模式（与自家一致） |
| 可模仿性 | 粉丝量（`author_fans_profile`(author_id)）+ 起量时长（`author_related_video_list_video` 视频发布时间倒推） | 粉丝 ≤50w 且近 3 个月起量 |

**销量分级（数据可得的客观锚点）**：月销 ≥1000 = 5 分；500-1000 = 4 分；200-500 = 3 分；<200 = 2 分；无数据 = 0 分（标注"数据缺失"）。

总分 ≥16 进深拆；<16 标注"参考价值有限"。数据缺失的维度记 0 分并标注"数据缺失"。

**输出契约（新增）：** 深拆通过的账号 → 写入 `经营档案/候选清单.md` 的"对标账号"节（S4 内容营销的输入）。

**Step 2 双源数据核验**

- 主源灰豚 + 副源蝉妈妈，同一指标（销量/客单/回购）双源取值
- 偏差 ≤20% → 取均值；>20% → 取低值并标注"数据口径差异大，谨慎参考"
- 记录时间口径（近 30 天/累计），不允许混用

**Step 3 六维拆解**

| 维度 | 拆什么 | 输出 |
|------|--------|------|
| 货盘结构 | 引流款/利润款/形象款、SKU 价格带分布 | 结构图 + 破价/凑单机制 |
| 标题关键词 | 前 8 字符、核心词命中、标题长度 | 关键词矩阵（含热度验证） |
| 内容钩子 | 拉其带货视频（`author_related_video_list_video`(author_id, 近7天) → 逐条 `video_detail_info` 取视频脚本/互动数据），拆前 3 秒钩子/中段/结尾 | 钩子句式库（3 条以上） |
| 评论 VoC | 近 30 天评论高频词/差评归因 | 买家在意点 + 差评机会点 |
| 信任背书 | 质检公示/源头实拍/资质/人群提示 | 可直接复制的背书清单 |
| 复购机制 | 回购率、老客营销、会员玩法 | 复购动作清单 |

**Step 4 合规过滤（零容忍）**

- 拆解笔记中引用的对方文案若含功效词 → 标注"❌ 对方违规，不可复制"，并给出合规替代表达
- 对方"低价引流 + 高毛利隐藏"等玩法可复制时，必须过毛利模型（净利率 ≥30% 才执行）

**Step 5 输出与存档**

- 结果存档至 `经营档案/竞品拆解笔记.md`
- 输出含「可复制清单 / 不可复制项（标注原因）/ 落地行动 3 条（带优先级 P0-P2 与时限）」

## 3. 质量门禁

- G1 数据核验：双源偏差记录完整，无单源硬编
- G2 拆解完整：六维全部覆盖（缺维须注明原因）
- G3 可执行：落地行动 3 条，每条 P0-P2 分级 + 时限 + 责任人
- G4 合规：无违规词被复制进自家建议

## 4. 输出自查清单（交付前必过）

- [ ] 对标对象通过 ≥16 分筛选（含可模仿性维度）
- [ ] 无货源模式已识别并降档
- [ ] 双源数据偏差已处理并标注
- [ ] 六维拆解完整
- [ ] 钩子句式 ≥3 条且可套用
- [ ] 违规词已过滤且给出合规替代
- [ ] 落地行动带 P 级与时限

## 5. 执行后复盘（写入执行日志）

- 拆解结论中哪些已落地执行？执行后数据（曝光/转化）如何？
- 若已落地行动未带来变化 → 分析是拆解不准还是执行偏差，修正筛选标准
- 命中率 <50% → 触发筛选评分权重调整

## 6. 异常与降级处理

| 异常 | 处理 |
|------|------|
| 双源均无该对象数据 | 标记"数据稀缺"，仅做内容层拆解（看视频），不输出销量结论 |
| 视频不可获取 | 用评论 VoC + 详情页代替内容层 |
| 候选对象全 <16 分 | 换类目关键词重新筛选，或接受降级并标注 |
