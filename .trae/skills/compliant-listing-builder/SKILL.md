# 合规建品生成器（Compliant Listing Builder）

借鉴社区 listing 生成器输出结构，内置本项目合规规则引擎 + **全成本毛利模型**，从源头保证合规且真实盈利。

## 0. 适用与触发

- 上架新商品 / 建品 / 优化标题或详情页 / 定价测算
- 赛马 A/B 分级铺货前的建品卡生成

## 1. 输入校验（门禁 G0）

必填：
- 商品名 + 进价（元/斤，来源 `商品价目总表.md`，歧义项必须先确认）
- 目标售价（可选，缺失则按毛利模型倒推）
- 每袋规格（克重/袋数，缺失则拒绝——毛利无法测算）

校验规则：
- 进价缺失或标注"待确认"→ 拒绝生成定价，仅生成合规文案
- 原料含目录外品种（如石斛花）→ 拒绝，提示目录内替代品
- 目标售价超出竞品价格带 ±30% → 提示人工确认

## 2. 执行流程

**Step 1 目录与合规判定**
- 逐原料查药食同源 106 种目录（以食用部位为准），输出合规结论
- 特殊原料（黄芪/西洋参/党参）→ 强制加「特殊人群不推荐」提示

**Step 2 关键词生成与热度验证**
- 生成核心词/长尾词/相关词矩阵（≤32 字符标题，核心词前 8 字符）
- 用灰豚或巨量算数验证候选词搜索热度：热度为 0 的长尾词剔除
- 输出保留 核心 3 词 + 长尾 5 词 + 相关 3 词

**Step 3 全成本毛利测算（净利率门禁）**

```
原料成本/袋 = 进价(元/斤) ÷ 500 × 每袋克重 × 该料占比
单盒成本 = Σ原料 + 包材(0.3-0.8元) + 内袋 + 标签
单件综合成本 = 单盒成本 + 快递(3-5元) + 平台佣金(≈5%) + 支付/运费险/退款损耗(≈2.5%)
净利率 = (售价 - 单件综合成本) / 售价
```

门禁：
- 净利率 ≥40% → 可上架（绿）
- 30-40% → 可上架但标注"薄利"（黄）
- <30% → 红标，建议提价或换规格，禁止直接上架

**Step 4 竞品价格交叉验证**
- 同款头部价格带（灰豚/搜索）：本定价不高于头部 +30%
- 低于头部 -40% → 标注"破价引流"定位，提示关注利润率

**Step 5 详情页与信任背书**
- 结构：原料实拍 → 配料表 → CMA 质检公示 → 冲泡方法 → 特殊人群提示 → 统一警示语
- 警示语固定：「本品为普通食品，不可替代药物治疗疾病」

## 3. 质量门禁

- G1 合规：输出全文过 compliance-check 零高风险
- G2 盈利：净利率 ≥30%（低于红标）
- G3 可执行：建品卡含 分级/标题/词矩阵/售价/毛利/主图要求/负责人/时限

## 4. 输出自查清单（交付前必过）

- [ ] 标题 ≤32 字且核心词前 8 字符
- [ ] 无禁用词（祛湿/降火/补气血/最/第一…）
- [ ] 9 项标签要素齐备
- [ ] 特殊人群提示与警示语存在
- [ ] 净利率计算含全部 5 项成本（原料/包材/快递/佣金/损耗）
- [ ] 竞品价格已交叉验证

## 5. 上架后反馈闭环（7-14 天）

- 第 7 天：罗盘查该 SKU 曝光/点击/收藏/转化
- 收藏率低（<3%）→ 回改标题关键词，重跑 Step 2
- 转化低但收藏高 → 优化详情页/价格，重跑 Step 3
- 结果记入执行日志，作为下一版规则依据

## 6. 异常与降级处理

| 异常 | 处理 |
|------|------|
| 进价待确认 | 只出文案，不出定价，标注"待进价确认" |
| 灰豚不可用 | 关键词热度验证降级为 WebSearch 抽样 |
| 目录判定存疑 | 输出时标注"待法务/官方确认"，不自行拍板 |
