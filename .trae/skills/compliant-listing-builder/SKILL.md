# 合规建品生成器（Compliant Listing Builder）

借鉴社区 product-listing-generator 类技能的输出结构，但**内置本项目合规规则引擎**，从源头保证上架即合规。

## 输入

- 商品名 + 进价（参考 `商品价目总表.md`，单位元/斤）
- 可选：竞品标题/价格参考

## 合规红线（内置，不可绕过）

### 1. 禁用词（出现即替换）
功效类：祛湿、去湿、除湿、健脾、养胃、降火、去火、清热、补气血、补血、益气、滋阴、壮阳、助眠、安神、解酒、排毒、减肥、瘦身、湿气
医疗类：治疗、治愈、药效、消炎、抗病毒、降三高、降糖、降压
绝对化：最、第一、唯一、根治、百分百

### 2. 允许的合规表达（场景词）
养气色、解腻、润喉、熬夜、护眼、暖身、温和、经典配方、日常所需、独立小袋、干净配料表

### 3. 硬性要素
- 标题 ≤32 字符，核心关键词放前 8 字符
- 9 项标签必备（品名/配料/净含量/生产日期/保质期/贮存条件/生产商/SC 编号/执行标准）
- 特殊人群提示：孕妇、哺乳期妇女及婴幼儿等特殊人群不推荐食用
- 统一警示语：本品为普通食品，不可替代药物治疗疾病

## 生成流程

1. 查目录：确认原料在药食同源 106 种目录内（目录以食用部位为准，见打法文档五）
2. 定分级：A 级（精做：标题+5图+详情+15-30s主图视频） / B 级（快上：标题+3图）
3. 生成商品名：原料堆叠 + 形态词（如：茯苓红豆薏米茶），不含任何功效词
4. 生成标题：核心词（前8字符）+ 长尾词 + 场景词，≤32 字
5. 生成关键词矩阵：核心词 / 长尾词（原料+人群+场景）/ 相关词（袋装、独立小袋、代用茶）
6. 生成详情页结构：原料实拍 → 配料表 → 质检公示（CMA 报告）→ 冲泡方法 → 警示语
7. 测算售价与毛利：按进价 + 目标毛利 60-75%（参考 19.9-49.9 价格带）

## 输出模板

```markdown
## SKU：{商品名}
- 分级：A / B
- 商品名（合规）：…
- 标题（≤32字）：…
- 关键词矩阵：核心词 / 长尾词 / 相关词
- 售价建议：¥xx（毛利 xx%）
- 详情页要点：…
- 主图要求：5 张 + 3:4 长主图 + 15-30s 视频
```

## 规则

- 每次生成必须过一遍禁用词清单，输出前自查
- 售价毛利低于 50% 或高于 80% 时标注提醒
- 目录外原料（如石斛花）拒绝生成，提示改用目录内替代品
