# 达人分销合作管理（Influencer Collab）

借鉴知乎社区「达人管理 = 数据和流程管理」方法论（筛选-建联-效果跟踪链路），封装为可量化、可追溯、可复盘的闭环流程，并针对食品类目做合规强化。

## 0. 适用与触发

- 找达人带货 / 扩展精选联盟分销 / 评估合作价值 / 复盘达人效果
- 新品起量期需外部流量 / 周度达人数据沉淀

## 1. 输入校验（门禁 G0）

必填（三选一即可启动，缺失则拒绝）：
- 目标货盘（商品 + 佣金比例 + 可给样品数）
- 目标人群（默认：25-45 岁女性、亚健康/熬夜/美容养颜人群，可覆盖）
- 候选达人清单（或筛选关键词）

校验规则：
- 佣金比例缺失 → 拒绝（佣金是毛利门禁的必需输入）
- 佣金 + 快递 + 平台费后净利率 <30% → 警告"该佣金不可持续"，需提价或降佣
- 目标人群与货盘明显不符（如保健功能向男性/老年人群）→ 提示复核

## 2. 执行流程

**Step 1 需求定义**
- 明确：主推 SKU、佣金（参考 15-20% 起步，按毛利倒推上限）、样品政策、合作时长（30 天试合作）
- 合规红线提前写入合作话术：达人不得宣称功效（祛湿/降火等），话术模板须过 compliance-check

**Step 2 达人筛选（客观评分，防人情选人）**

候选达人按四项打分（各 1-5）：
- 品类相关度（带货历史含食品/养生/滋补类目 = 5 分；纯美妆/服装 = 1 分）
- 受众匹配（粉丝画像女性占比 ≥60% 且 25-45 岁为主 = 5 分，用灰豚达人画像核）
- 带货能力（近 30 天场均 GMV / 视频带货单量，达标 = 5 分）
- 合规记录（历史视频无功效宣称违规 = 5 分；有违规 = 1 分，直接降权）
总分 ≥16 进合作池；12-15 待定；<12 淘汰。食品类目**合规记录一票否决**（存在医疗/功效宣称且未整改 → 直接淘汰）。

**Step 3 匹配度量化**
- 输出达人对比表：粉丝画像 / 带货能力 / 客单匹配 / 佣金预算占 GMV 比
- 每名达人标注「预期 ROI 区间」（参考其近 30 天视频转化率 × 本品客单）
- 排序取前 N（按预算）进入建联，不超额

**Step 4 建联（批量 + 话术合规）**
- 精选联盟邀约为主，附私信触达（话术含：商品卖点合规版 + 佣金 + 样品政策）
- 话术生成后先过 compliance-check，再发出；含功效词的邀请话术 = 违规，一律不发
- 记录建联时间，3 天无回复 → 跟进 1 次，仍无 → 标记"未响应"

**Step 5 效果跟踪（数据沉淀）**
- 达人内容发布后采集：视频曝光/互动/带货单量/GMV（灰豚视频带货数据 + 抖店后台）
- 逐达人写入 `达人效果档案库.md`（字段：达人/受众画像/带货表现/客单/GMV/退货率/合规状态）
- 每周汇总：确认哪些达人是有效投入，哪些无效

**Step 6 ROI 复盘（续约门禁）**
- 单达人 ROI = 该达人带来的 GMV ÷（佣金 + 样品 + 维护成本）
- ROI <1 → 停止续约，标记"低效达人"；1-2 → 观察期 1 个月；≥2 → 优先续约 + 加预算
- 每月输出 1 条「达人策略调整建议」（如：加大某类达人、调整佣金结构）

## 3. 质量门禁

- G1 筛选客观：每位进池达人都有四项评分 + 合规记录（缺合规记录 = 不评高分）
- G2 毛利安全：佣金测算后净利率 ≥30%，否则该达人不合作
- G3 合规：全部话术/达人内容引用过 compliance-check，零功效宣称
- G4 可追溯：每位达人效果档案字段齐全，无"感觉很好"式结论

## 4. 输出自查清单（交付前必过）

- [ ] 进池达人均有四项评分与合规记录
- [ ] 佣金后净利率已测算（≥30%）
- [ ] 邀请话术已过合规检查（无功效词）
- [ ] 效果档案字段完整（GMV/退货率/合规状态）
- [ ] 续约/淘汰决策有 ROI 依据

## 5. 执行后复盘（写入执行日志）

- 试合作 30 天结束：预测 ROI vs 实际 ROI，偏差 >50% → 检查是筛选不准还是执行偏差
- 复盘"被淘汰达人"是否误杀（如测评期数据未起量但品类匹配度高）→ 修正评分权重
- 新识别合规风险（达人私自改话术宣称功效）→ 记入档案库并固化"样品寄送附合规须知"
- 规则更新 → 版本号 +1，在 7. 版本记录登记

## 6. 异常与降级处理

| 异常 | 处理 |
|------|------|
| 灰豚达人数据不可用 | 降级为蝉妈妈达人榜 + WebSearch 账号表现；仍无 → 仅做内容层观察，不评带货能力分 |
| 达人画像缺失 | 该项记 0 分并标注"数据缺失"，不进高分区 |
| 全部候选 <16 分 | 换关键词/换人群重新筛选，或接受"暂无合适达人，暂缓投放" |
| 达人拒绝合作 | 记入档案库"已触达未合作"，3 个月后可复触 |
| 合作中达人违规宣传 | 立即下架合作视频 + 记录，评估是否走平台举报 |
