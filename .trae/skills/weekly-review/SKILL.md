# 复盘进化（S6）

闭环终点也是起点：修订后的规则直接影响 S1-S5 下次执行。

## 0. 触发
- 周日 30 分钟例行 / 月末 60 分钟战略 / 任何技能触发"规则待修订"

## 1. 输入契约
必填：S0-S5 本周输出（仪表盘/候选清单/货架日志/内容记录/达人档案）
- 缺失项 → 标注"本周未执行"，不补数

## 2. 分级执行

**周日 30 分钟版：**
1. 漏斗对比：本周 vs 上周（曝光/点击率/转化率/GMV），定位瓶颈段
2. 情报命中率：S1 上周预判的候选/趋势，实际验证多少？<60% → 修订评分权重
3. 内容 A 类率：借鉴选题实际表现 vs 对标，<50% → 修订选题标准
4. 达人 ROI 汇总：续约/淘汰/调整（按 M6 ROI 门禁）
5. 输出：`经营档案/周复盘.md`（下周决策 ≤3 条 + 规则修订 N 条）

**月末 60 分钟版：**
1. 货盘取舍：销量 top 20% 集中资源；14 天无成交 SKU 下架候选
2. 预算分配：样品/佣金/投流（投流 ≤ 月利润 20%）
3. 知识库更新：修订《经营手册》对应模块，版本号 +1
4. 技能规则版本 +1（各技能 7. 版本记录登记）

## 3. 输出契约
- `经营档案/周复盘.md` / `经营档案/月复盘.md`
- 规则修订表：技能/规则项/旧值/新值/依据 → 逐条回写对应技能与《经营手册》

## 4. 数据回流
- 每条规则修订必须落到文件（可查版本变化），禁止口头修订
