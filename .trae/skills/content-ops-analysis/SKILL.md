# 内容账号运营分析（Content Ops Analysis）

借鉴 B 站「自媒体运营分析 skill」的设计思路（监控博主更新/对标账号新爆款/选题标题表达学习/自家主页表现分析），针对养生茶类目封装为「自家盘点 → 对标追踪 → 选题库沉淀 → 下周内容计划」的内容运营闭环。

## 0. 适用与触发

- 周度/月度内容复盘 / 选题枯竭需方向 / 对标账号内容学习
- 内容引流效果不佳，需定位问题（选题/标题/表达）

## 0.5 契约（三合一体系）
- 输入契约：选题库+对标+热词
- 分级执行：日常 5 分钟版（发布后数据回填与快速检查）/ 攻坚 30 分钟版（周度内容复盘 + 下周 5 条计划排期）
- 输出契约：经营档案/周内容计划.md → 发布
- 数据回流：A 类率<50% 修选题

## 1. 输入校验（门禁 G0）

必填：
- 自家账号（抖音号，用于罗盘/创作者后台取数）
- 对标账号清单（≥3 个，来源：competitor-teardown 筛选出的对标店铺账号）

校验规则：
- 对标账号 <3 个 → 拒绝，先跑 competitor-teardown 补名单
- 自家账号未绑定罗盘 → 提示先开通，取数口径缺则输出降级版

## 2. 执行流程

**Step 1 自家内容表现盘点（近 7 天）**

按内容类型（口播/图文/混剪/挂车/纯引流）分组统计：
- 播放/点赞/评论/转发/收藏，带货视频另计：挂车点击率、成交单量
- 输出「表现分层」：**用自身基线，不对标百万粉账号**（不同体量不可比，M8）：
  - A 类：播放 ≥ 自身近 30 天均值 × 1.5，或直接出单
  - B 类：均值 ± 30%
  - C 类：低于自身均值 50%
- 定位问题：播放低=选题/封面；互动低=表达/文案；转化低=挂车位置/信任背书
- 分层口径记入日志，周复盘时对比"本周 A 类占比 vs 上周"，而非对标播放

**Step 2 对标账号新爆款追踪**

- 灰豚链路：`author_related_video_list_video`(author_id, 近7天) 取各对标账号近 7 天新发布视频，按互动指标（点赞 `digg_count`）降序取前 3 条；蝉妈妈链路：`video_understanding` 拆视频脚本/卖点
- 每条拆：选题 / 标题（前 8 字钩子）/ 封面 / 前 3 秒 / 表达结构 / 是否挂车（`video_detail_info` 取视频脚本、互动数据与关联商品）
- 合规检查：若其内容含功效宣称（祛湿/降火等）→ 标注"❌ 对方违规，选题可借、话术不可抄"

**Step 3 选题与标题库沉淀**

- 新爆款选题 → 映射自家货盘：有货 → 进「下周候选选题」；无货 → 记「潜在补货线索」
- 标题钩子句式提炼 ≥3 条（如"XX 的人注意了…""没想到…""实测…"），进钩子句式库
- 每周更新选题库，标记来源与时效（热点型/常青型）

**Step 3.5 模板化产出（30 分钟/条，单人可执行）**

按模板填空产出 1 条内容，不追求原创，追求稳定达标：

1. 选题（30 秒）：从选题库取 1 条（本周轮转：热点/常青/信任背书）
2. 标题（2 分钟）：套标题公式——"XX 的人注意了…"/"没想到…"/"实测 7 天…"+ 品类词
3. 脚本（10 分钟）：前 3 秒钩子（痛点提问）→ 中段（原料实拍 3 个镜头+冲泡演示）→ 结尾（场景词+挂车引导）
4. 制作（15 分钟）：AI 生成配音/字幕/封面（封面大字 ≤5 字），素材用原料实拍库
5. 合规自检（2 分钟）：过 compliance-check，功效词零容忍；挂车视频确认商品卡正确
6. 发布并回填：数据回填 `经营档案/周内容计划.md`

**Step 4 输出下周内容计划**

- 5 条内容排期：3 条引流（选题库）+ 1 条挂车转化 + 1 条信任背书（质检/原料实拍）
- 每条标注：选题 / 标题钩子 / 表达结构 / 合规检查结论 / 发布时间
- 与 daily-hot-intel 联动：本周热卖词进入标题；与 store-launch-sop 联动：新品上架同步内容

## 3. 质量门禁

- G1 数据真实：自家数据来自罗盘/创作者后台，标口径与时间
- G2 对标可追：对标账号每次追踪有记录（账号/日期/选题/播放），不凭记忆
- G3 合规：计划内每条内容过 compliance-check，功效词零容忍
- G4 可执行：下周计划含具体选题与排期，无"多拍点视频"式空话

## 4. 输出自查清单（交付前必过）

- [ ] 自家近 7 天数据按类型分层，问题有定位
- [ ] 对标账号新爆款 ≥3 条已拆（选题/标题/钩子/挂车）
- [ ] 选题库更新，违规话术已标注不可抄
- [ ] 下周 5 条内容排期齐全（选题/钩子/合规/时间）

## 5. 执行后复盘（写入执行日志）

- 下周复盘：**用自身基线对比**——本周 A 类占比 vs 上周 A 类占比，环比下降 >30% → 调整选题判断标准；借用的对标选题实际表现 vs 自身基线，而非对标播放
- 自家 A 类内容特征沉淀：什么选题/标题/时长出单 → 加权重复
- 记录误判：高播放借鉴但 0 转化 → 检查是人群不匹配还是表达问题
- 规则更新 → 版本号 +1，在 7. 版本记录登记

## 6. 异常与降级处理

| 异常 | 处理 |
|------|------|
| 灰豚/蝉妈妈不可用 | 降级为 WebSearch 关键词搜当日爆款视频；仍无 → 只做自家盘点 |
| 自家数据拿不到 | 输出降级版（仅对标学习 + 内容计划），标注"自家数据待补" |
| 对标账号无新爆款 | 扩对标清单或换关键词，接受"本周无新选题"不硬凑 |
| 借鉴内容含违规词 | 选题保留、话术重写为合规版（场景词替换） |
