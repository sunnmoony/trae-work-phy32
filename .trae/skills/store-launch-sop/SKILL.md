# 店铺起店与货架运营 SOP（Store Launch SOP）

借鉴 B 站抖店运营教程（商品卡玩法/7天起店/动销/搜索流量优化）的结构，剔除卖课话术与刷单套路，封装为**合规优先、数据盯盘、节奏固定**的起店执行流程。只适用于自家货架运营，不用于无货源代发。

## 0. 适用与触发

- 新店开通后准备起店 / 店铺动销不足 / 新品上架后拿不到流量
- 每周例行货架运营检查 / 大促前货架优化

## 1. 前置校验（门禁 G0）

必填：
- 店铺资质：营业执照经营范围含食品销售/预包装食品（缺失 → 先走开店资质清单）
- 货盘：≥3 个 SKU 已完成建品（合规 + 毛利门禁，缺 → 先跑 compliant-listing-builder）
- 合规基线：店铺公示 9 项标签要素（缺 → 先跑 compliance-check）

校验规则：
- 以上任一缺失 → 拒绝执行起店步骤，只输出"前置待办清单"
- 目标含糊（无时间/无预算）→ 提示补齐，默认按 7 天自然流起店

## 2. 执行流程

**Step 1 新店基础设置（13 项清单）**

| 分类 | 项目 |
|------|------|
| 基础 | 店铺名称/LOGO/简介（含品类词）、发货地址、退货地址 |
| 交易 | 运费模板（≥2 档）、运费险、支付方式、自动回复 |
| 服务 | 客服在线时长、售后规则、发货时效承诺（48h） |
| 资质 | 食品经营许可/SC 公示位、质检报告上传、类目资质核验 |
| 商品 | 默认 SKU 图、详情页模板（含 9 项标签） |

完成后逐项勾选，全部通过才进入 Step 2。

**Step 2 商品卡原理与卡位**

商品卡 = 货架场流量入口（搜索/商城推荐/猜你喜欢），不依赖直播与短视频。卡位三要素：
- **标题**：核心词前置 ≤8 字符，覆盖 搜索词 + 属性词（如"菊花枸杞茶 养生花茶 独立小袋"）
- **主图**：白底 + 卖点字 ≤3 个，首图过检（无功效词/无绝对化）
- **属性**：类目属性全填（口味/规格/保质期/产地），属性完整度影响曝光

卡位判断：上架 48h 后罗盘看「商品卡曝光」，无曝光 → 标题/属性有问题，回 Step 2 修。

**Step 3 7 天起店节奏表（固定节奏，不拍脑袋）**

| 天 | 动作 | 当日数据目标 |
|----|------|-------------|
| D1 | Step 1 基础设置 + Step 2 首批 3-5 个 SKU 上架 | 上架完成，无驳回 |
| D2 | 补齐属性 + 自查合规 + 确认搜索词命中 | 商品卡开始有曝光 |
| D3 | 启动合规动销（Step 4）+ 优化 0 曝光 SKU 标题 | 至少 1 个 SKU 出单 |
| D4 | 盯盘数据，爆款加权（标题同步热词） | 曝光→点击率 ≥3% |
| D5 | 补货架坑位（同类变体/组合装），评价引导（合规话术） | 主推 SKU 有评价 |
| D6 | 检查体验分（≥4.5，低于 → 排查服务/物流） | 体验分 ≥4.5 |
| D7 | 周复盘：转化漏斗 + 下周计划 | 输出复盘 1 页 |

任一步数据未达标 → 修对应环节，不进入下一步（防"流水账式起店"）。

**Step 4 合规动销（红线明确）**

动销目的：让商品卡获得初始成交权重。合规方式：
- 老客/私域真实复购（社群/朋友圈，真实订单）
- 精选联盟低佣达人带货（走 douyin-influencer-collab）
- 直播间/短视频挂车（自己账号内容引流）
红线（禁止）：
- 刷单/自买自评/虚假物流 → 平台清洗，**评论区的教训：行为不像正常人就会被清号**
- 诱导好评（返现/好评返红包）→ 违规

动销目标：每个 SKU 起量期 ≥5 单真实成交 + 体验分不降。

**Step 5 新品上架后搜索流量优化（拿搜索流量四步）**

1. 标题诊断：核心搜索词是否前置？热度词是否覆盖？（用巨量算数/灰豚验证热度，0 热度词剔除）
2. 主图诊断：首图点击率低（<2%）→ A/B 换图（卖点字/场景图），48h 后再测
3. 属性与详情：缺项补齐；详情页挂质检报告图（信任背书）
4. 评价冷启动：随单合规话术引导评价（不返现），3-5 条带图评价后再看搜索排名

**Step 6 数据盯盘（罗盘漏斗）**

- 每日 5 分钟：曝光 → 点击 → 加购 → 转化 四段漏斗
- 瓶颈定位：曝光低=标题/属性问题；点击低=主图问题；转化低=价格/详情/评价问题
- 渠道归因：搜索 vs 推荐 vs 商城，哪段掉 → 修哪段（借鉴数据分析视频的"瓶颈渠道判断"逻辑）
- 记录到 `货架运营日志.md`

## 3. 质量门禁

- G1 前置齐备：资质/货盘/合规基线全部通过才起店
- G2 节奏执行：7 天每天有动作与数据目标，无跳步
- G3 动销合规：无刷单/诱导好评记录（日志可查）
- G4 数据驱动：每周复盘含漏斗数据与瓶颈定位，无"感觉"式结论

## 4. 输出自查清单（交付前必过）

- [ ] 13 项基础设置逐项勾选完成
- [ ] 商品卡三要素（标题/主图/属性）检查完毕
- [ ] 7 天节奏表当天目标已达成才继续
- [ ] 动销方式均在合规清单内
- [ ] 罗盘漏斗已记录且瓶颈有定位

## 5. 执行后复盘（写入执行日志）

- 每周：实际出单 vs 节奏表目标，偏差 >50% → 检查是货盘问题还是执行问题
- 每月：起店动作中哪一步 ROI 最高（基础设置/动销/搜索优化）→ 固化到 SOP
- 体验分波动：低于 4.5 时记录原因（物流/服务/品控），反推改进
- 规则更新 → 版本号 +1，在 7. 版本记录登记

## 6. 异常与降级处理

| 异常 | 处理 |
|------|------|
| 资质未齐 | 只输出"前置待办清单"，不起店 |
| 上架被驳回 | 收集驳回原因 → 过 compliance-check 修订后再上 |
| 7 天无单 | 排查：曝光无 → 标题/属性；有点击无转化 → 价格/评价；全无 → 换引流款 SKU |
| 数据工具不可用 | 降级为抖店后台手动看数，标注"人工口径" |
| 体验分骤降 | 立即停售整改（物流/售后），修复后再恢复 |
