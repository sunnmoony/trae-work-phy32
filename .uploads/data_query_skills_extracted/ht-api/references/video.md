# 视频 API 参考

本文件只包含已完整满足 `ht-api` 标准能力的正式接口。API 名和摘要使用 HT API 定义，HTTP method、path 和查询参数使用当前可执行接口定义。

## API 索引

| API                                                            | 摘要                                                                                                                                                                      |
|----------------------------------------------------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `video_library_custom_search_video`                            | 核心用途：通过关键词自定义搜索和多条件筛选热门视频。注意：本接口是唯一支持常规视频关键词检索的接口（视频榜单类接口均不支持关键词）。当用户意图包含“视频标题关键词”、“主题”或“特定事件”（如：搜XX视频、找关于XX的视频）时，必须且只能使用此接口。支持结合时间、基础信息、互动指标等组合筛选并排序。                  |
| `video_commerce_video_library_custom_search_top_selling_video` | 核心用途：通过商品或视频关键词自定义搜索带货视频。注意：本接口是唯一支持带货视频关键词检索的接口（带货榜单类接口均不支持关键词）。当用户想要按“特定商品链接”或“视频关键词”（如：找洗面奶的带货视频、搜包含XX商品的视频）时，必须且只能使用此接口。支持多条件组合筛选并按销量/销售额等指标排序。                     |
| `video_top_selling_commerce_video_rank_period`                 | 获取历史周期的热销视频榜单，榜单按照周期内视频带货销量降序取TOP视频列表，列表包括：视频基础信息、视频互动数据、视频销售数据。绝对限制：本榜单接口不支持任何形式的关键词、商品名、主题检索！如果用户表达了想看“某个具体商品（如：洗面奶）”或“包含某关键词”的带货榜单，禁止调用此接口，必须去调用 api_id: 64 (带货视频库)。 |
| `video_detail_info`                                            | 获取指定视频的基础信息、周期内的关键数据指标、关联商品列表、视频脚本、观众画像及视频评论。                                                                                                                           |

## API 详情

### video_library_custom_search_video
核心用途：通过关键词自定义搜索和多条件筛选热门视频。注意：本接口是唯一支持常规视频关键词检索的接口（视频榜单类接口均不支持关键词）。当用户意图包含“视频标题关键词”、“主题”或“特定事件”（如：搜XX视频、找关于XX的视频）时，必须且只能使用此接口。支持结合时间、基础信息、互动指标等组合筛选并排序。

| 参数              | 必填 | 说明                                                                                                            |
|-----------------|----|---------------------------------------------------------------------------------------------------------------|
| from            | 是  | 页码，最小值为 1，每页返回 10 条                                                                                           |
| hideMusic       | 否  | 是否隐藏汽水音乐：true 隐藏，false 不隐藏                                                                                    |
| tag1            | 否  | 一级视频标签 ID                                                                                                     |
| tag2            | 否  | 二级视频标签 ID                                                                                                     |
| tag3            | 否  | 三级视频标签 ID                                                                                                     |
| hours           | 否  | 查询周期：近 2 小时 2、近 6 小时 6、近 12 小时 12、近 24 小时 24、近 3 天 72、近 7 天 168、近 15 天 360、近 30 天 720、近 60 天 1440、近 90 天 2160 |
| sortField       | 是  | 排序字段：发布时间 `aweme_ctime`、点赞 `digg_count`、评论 `comment_count`、收藏 `colCount`、分享 `share_count`                     |
| sortMod         | 是  | 排序方式：升序 `asc`、降序 `desc`                                                                                       |
| withFusionGoods | 否  | 是否带货视频：true 是，false 否                                                                                         |
| diggRange       | 否  | 点赞数区间，使用 `~` 分隔，例如 `50000~100000`                                                                             |
| durationRange   | 否  | 视频时长：`*-15`、`15-30`、`30-60`、`60-*`                                                                            |
| timeRange       | 否  | 一天内发布时间段，例如 `02:00-10:00`                                                                                     |
| followerRange   | 否  | 视频作者粉丝数区间                                                                                                     |
| maxGender       | 否  | 观众主要性别：男性为主传 `男`，女性为主传 `女`                                                                                    |
| maxAge          | 否  | 观众主要年龄，例如 `18-23`、`24-30`、`31-40`、`41-50`、`50-*`                                                              |
| maxArea         | 否  | 观众主要省份                                                                                                        |
| maxCity         | 否  | 观众主要城市                                                                                                        |
| type            | 否  | 特殊类型筛选：低粉高赞 `lowF_highD`                                                                                      |
| currentPolitics | 否  | 是否隐藏政务类视频：true 隐藏，false 不隐藏                                                                                   |
| imageTxt        | 否  | 是否图文视频：true 是，false 否                                                                                         |
| advertisement   | 否  | 是否星图视频：true 是，false 否                                                                                         |
| aiVideo         | 否  | 是否 AI 视频：true 是，false 否                                                                                       |



### video_commerce_video_library_custom_search_top_selling_video

核心用途：通过商品或视频关键词自定义搜索带货视频。注意：本接口是唯一支持带货视频关键词检索的接口（带货榜单类接口均不支持关键词）。当用户想要按“特定商品链接”或“视频关键词”（如：找洗面奶的带货视频、搜包含XX商品的视频）时，必须且只能使用此接口。支持多条件组合筛选并按销量/销售额等指标排序。

| 参数              | 必填   | 说明                                                                                               |
|-----------------|------|--------------------------------------------------------------------------------------------------| 
| `from`          | 是    | 页码，从 `1` 开始。                                                                                     |
| `hours`         | 是    | 查询周期小时数。传 `24` 时服务层会改为 `60`；商品链接搜索会固定为 `719`。                                                    |
| `sortField`     | 是    | 排序字段，例如点赞 `digg_count`、商品浏览量 `visitors`、视频销量 `video_sales`、视频销售额 `video_gmv`、发布时间 `aweme_ctime`。 |
| `sortMod`       | 否    | 排序方式：升序 `asc`、降序 `desc`。                                                                         |
| `keyword`       | 否    | 商品标题、商品链接或商品口令关键词。                                                                               |
| `goodsTag`      | 否    | 商品搜索标记；按商品链接或口令定位时传 `true`。                                                                      |
| `diggRange`     | 否    | 视频点赞数区间。                                                                                         |
| `tag1`          | 否    | 一级视频标签 ID。                                                                                       |
| `tag2`          | 否    | 二级视频标签 ID。                                                                                       |
| `tag3`          | 否    | 三级视频标签 ID。                                                                                       |
| `productId`     | 否    | 商品 ID。                                                                                           |
| `uid`           | 否    | 达人 UID。                                                                                          |
| `durationRange` | 否    | 视频时长区间。                                                                                          |
| `durationList`  | 否    | 视频时长区间多选。                                                                                        |
| `createTimes`   | 否    | 视频发布时间范围，按开始、结束时间传两个值。                                                                           |
| `goodsCates`    | 否    | 商品品类 ID。                                                                                         |
| `subIds`        | 否    | 商品细分品类 ID 列表。                                                                                    |
| `leafIds`       | 否    | 商品叶子类目 ID 列表。                                                                                    |
| `goodsSource`   | 否    | 商品来源。                                                                                            |
| `visitorRange`  | 否    | 商品浏览量区间。                                                                                         |
| `sales`         | 否    | 商品销量区间。                                                                                          |
| `prices`        | 否    | 商品价格区间，单位元。                                                                                      |
| `followerRange` | 否    | 视频作者粉丝数区间。                                                                                       |
| `maxGender`     | 否    | 粉丝画像主要性别。                                                                                        |
| `maxAge`        | 否    | 粉丝画像主要年龄。                                                                                        |
| `maxArea`       | 否    | 粉丝画像主要省份。                                                                                        |
| `maxCity`       | 否    | 粉丝画像主要城市。                                                                                        |
| `timeRange`     | 否    | 一天内发布时间段，例如 `02:00-10:00`。                                                                       |
| `searchMode`    | 否    | 查询模式：快捷搜索 `0`、精确搜索 `1`、ID 搜索 `2`。                                                                |


### video_detail_info

获取指定视频的基础信息、周期内的关键数据指标、关联商品列表、视频脚本、观众画像及视频评论。

| 参数    | 必填 | 说明   |
|-------|----|------|
| `aId` | 是  | 视频Id |

### video_top_selling_commerce_video_rank_period

获取历史周期的热销视频榜单，榜单按照周期内视频带货销量降序取TOP视频列表，列表包括：视频基础信息、视频互动数据、视频销售数据。绝对限制：本榜单接口不支持任何形式的关键词、商品名、主题检索！如果用户表达了想看“某个具体商品（如：洗面奶）”或“包含某关键词”的带货榜单，禁止调用此接口，必须去调用 api_id: 64 (带货视频库)。

| 参数           | 必填 | 说明                                                                                                 |
|--------------|----|----------------------------------------------------------------------------------------------------|
| `hours`      | 是  | 快捷周期：近24小时 `24`、近3天 `72`、近7天 `168`；与 `periodType`/`time` 二选一。                                      |
| `sortField`  | 是  | 排序字段 发布时间：aweme_ctime，点赞：digg_count，销售额:video_gmv ,销量：video_sales 分享：share_count  评论：comment_count |
| `sortMod`    | 否  | 控制器会固定使用降序 `desc`；传入 `asc` 不生效。                                                                    |
| `cate`       | 否  | 类目id                                                                                               |
| `level`      | 否  | 类目层级                                                                                               |
| `cat1`       | 否  | 类目所属1级类目id  若1级高则为空                                                                                |
| `periodType` | 是  | `hours` 为空时必填：日榜 `0`、周榜 `1`、月榜 `2`。                                                                |
| `time`       | 是  | `hours` 为空时必填。日榜格式 `yyyy-MM-dd`，周榜格式 `MM月dd日-MM月dd日`，月榜格式 `yyyy年MM月`。                              |
| `from`       | 是  | 页码 最小值为1 （每页返回10条）                                                                                 |
