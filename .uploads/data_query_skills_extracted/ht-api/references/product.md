# 商品 API 参考

本文件只包含已完整满足 `ht-api` 标准能力的正式接口。API 名和摘要使用 HT API 定义，HTTP method、path 和查询参数使用当前可执行接口定义。

## API 索引

| API                                                             | 摘要                                                                                                  |
|-----------------------------------------------------------------|-----------------------------------------------------------------------------------------------------|
| `product_library_custom_search_product`                         | 通过商品属性/商品标题关键字、商品基础信息和商品关键数据指标多条件组合，筛选出满足条件的商品列表，支持按指定指标排序。列表信息包括：商品标题、商品头图、商品价格、商品数据指标、商品近30天销量趋势。 |
| `product_basic_info`                                            | 获取指定商品的基础信息。                                                                                        |
| `product_audience_profile`                                      | 获取指定商品的观众或成交画像（性别年龄地区）                                                                              |
| `product_key_metrics_live_video_author_sales_data_daily_detail` | 获取指定商品在周期内的关键数据指标明细，按日返回各数据指标值，包括：商品数据、销售数据、关联直播数据、关联视频数据、关联达人数据。                                   |
| `product_related_commerce_author_list`                          | 获取指定商品在周期内关联的带货达人列表，列表信息包含：达人基础信息、该达人在商品上产生的销售数据（如：销量、销售额、关联直播数、关联视频数等）。                            |
| `product_related_commerce_live_list`                            | 获取指定商品在周期内关联的带货直播列表，列表信息包括：直播基础信息、商品在该直播间的销售数据。                                                     |
| `product_related_commerce_video_list`                           | 获取指定商品在周期内关联的带货视频列表，列表信息包括：视频基础信息、商品在该视频产生的销售数据。                                                    |
| `product_top_selling_product_rank_period`                       | 获取历史周期的商品热销榜单，榜单按周期内商品销量降序取TOP商品列表，列表信息包括：商品基础信息、销售数据、近30天销量趋势。                                     |
| `product_top_selling_live_product_rank_period`                  | 获取历史周期的直播商品热销榜单，榜单按周期内商品直播销量降序取TOP商品列表，列表信息包括：商品基础信息、销售数据、近30天直播销量趋势。                               |
| `product_top_selling_video_product_rank_period`                 | 获取历史周期的视频商品热销榜单，榜单按周期内商品视频销量降序取TOP商品列表，列表信息包括：商品基础信息、销售数据、近30天视频销量趋势。                               |

## API 详情

### product_library_custom_search_product

通过商品属性/商品标题关键字、商品基础信息和商品关键数据指标多条件组合，筛选出满足条件的商品列表，支持按指定指标排序。列表信息包括：商品标题、商品头图、商品价格、商品数据指标、商品近30天销量趋势。

| 参数              | 必填   | 说明                                                                                                                                                                                                                                                                                                                                                                                          |
|-----------------|------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `keyword`       | 否    | 商品关键词                                                                                                                                                                                                                                                                                                                                                                                       |
| `sortField`     | 否    | 排序字段 页面价：price   平均到手价：livePrice30   佣金比例：cosRatio  近7天 销量：sales7     近7天 商品卡销量：cardSales7   近7天 销售额：gmv7   近7天 商品卡销售：cardGmv7    近7天 关联直播：liveNum7  关联视频l:aweme_count 关联达人：user_count   昨天 销量：sales_daily 昨天  商品卡销量：cardSales1 昨天  销售额：gmv_daily 昨天  商品卡销售：cardGmv1  昨天 关联直播：live_num 近30天 销量：sales30  近30天 商品卡销量：cardSales30 近30天 销售额：gmv30  近30天 商品卡销售：cardGmv30     近30天 关联直播：liveNum30 |
| `sortMod`       | 否    | 排序方式：升序 `asc`、降序 `desc`。                                                                                                                                                                                                                                                                                                                                                                    |
| `prices`        | 否    | 页面价区间单位元                                                                                                                                                                                                                                                                                                                                                                                    |
| `unitPrice`     | 否    | 平均价价区间单位元                                                                                                                                                                                                                                                                                                                                                                                   |
| `cosRatioRange` | 否    | 佣金比例 最大值为1 示例：0.1-0.2   or 0.15-*代表>=0.15                                                                                                                                                                                                                                                                                                                                                   |
| `salesC`        | 否    | 总销量区间 示例：5000-6000    or  5000-*代表>=5000                                                                                                                                                                                                                                                                                                                                                    |
| `liveSalesC`    | 否    | 直播销量区间 示例：5000-6000    or  5000-*代表>=5000                                                                                                                                                                                                                                                                                                                                                   |
| `videoSalesC`   | 否    | 视频销量区间 示例：5000-6000    or  5000-*代表>=5000                                                                                                                                                                                                                                                                                                                                                   |
| `cardSalesC`    | 否    | 商品卡销量区间 示例：5000-6000    or  5000-*代表>=5000                                                                                                                                                                                                                                                                                                                                                  |
| `gmvC`          | 否    | 总销售额区间单位元 示例：5000-6000    or  5000-*代表>=5000                                                                                                                                                                                                                                                                                                                                                |
| `liveGmvC`      | 否    | 直播销售额区间单位元 示例：5000-6000    or  5000-*代表>=5000                                                                                                                                                                                                                                                                                                                                               |
| `videoGmvC`     | 否    | 视频销售额区间单位元 示例：5000-6000    or  5000-*代表>=5000                                                                                                                                                                                                                                                                                                                                               |
| `cardGmvC`      | 否    | 商品卡销售额区间单位元 示例：5000-6000    or  5000-*代表>=5000                                                                                                                                                                                                                                                                                                                                              |
| `viewC`         | 否    | 浏览量 示例：5000-6000    or  5000-*代表>=5000                                                                                                                                                                                                                                                                                                                                                      |
| `orderRateC`    | 否    | 转化率最大值为1  示例：0.1-0.2   or 0.15-*代表>=0.15                                                                                                                                                                                                                                                                                                                                                    |
| `searchType`    | 否    | 统计周期：昨日 `0`、近7天 `1`、近30天 `2`。                                                                                                                                                                                                                                                                                                                                                               |
| `podcastRange`  | 否    | 关联达人数                                                                                                                                                                                                                                                                                                                                                                                       |
| `awemeRange`    | 否    | 关联视频数                                                                                                                                                                                                                                                                                                                                                                                       |
| `liveNumC`      | 否    | 关联直播数                                                                                                                                                                                                                                                                                                                                                                                       |

| `liveRatio`     | 否    | 销售渠道单选：直播占比区间                                                                                                                                                                                                                                                                                                                                                                               |

| `userType`      | 否    | 账号类型  达人:daren  店铺：shop  品牌：brand                                                                                                                                                                                                                                                                                                                                                           |

| `province`      | 否    | 发货地省份                                                                                                                                                                                                                                                                                                                                                                                       |
| `city`          | 否    | 发货地城市                                                                                                                                                                                                                                                                                                                                                                                       |
| `from`          | 是    | 页码最小值是1 每页返回20条数据                                                                                                                                                                                                                                                                                                                                                                           |

### product_basic_info

获取指定商品的基础信息。

| 参数    | 必填   | 说明   |
|-------|------|------|
| `pid` | 是    | 商品id |

### product_audience_profile

| 参数    | 必填   | 说明                     |
|-------|------|------------------------|
| `pId` | 是    | 商品id                   |
| `tag` | 否    | 不传表示观众画像；传 `1` 表示成交画像。 |

### product_key_metrics_live_video_author_sales_data_daily_detail

获取指定商品在周期内的关键数据指标明细，按日返回各数据指标值，包括：商品数据、销售数据、关联直播数据、关联视频数据、关联达人数据。

| 参数          | 必填   | 说明                                                 |
|-------------|------|----------------------------------------------------|
| `pid`       | 是    | 商品id                                               |
| `startTime` | 是    | 开始时间   格式：2026-01-01， 最早日期支持到3年前                   |
| `endTime`   | 是    | 结束时间  格式：2026-01-01， 最早日期支持到3年前， 开始时间和结束时间差不超过365天 |

### product_related_commerce_author_list

获取指定商品在周期内关联的带货达人列表，列表信息包含：达人基础信息、该达人在商品上产生的销售数据（如：销量、销售额、关联直播数、关联视频数等）。

| 参数          | 必填   | 说明                                                    |
|-------------|------|-------------------------------------------------------|
| `type`      | 是    | 带货方式， 直播带货：live， 视频带货：video                           |
| `keyword`   | 是    | 搜索关键词                                                 |
| `pid`       | 是    | 商品id                                                  |
| `startTime` | 是    | 开始时间   格式：2026-01-01， 最早日期支持到3年前                      |
| `endTime`   | 是    | 结束时间  格式：2026-01-01， 最早日期支持到3年前， 开始时间和结束时间差不超过365天    |
| `sort`      | 是    | 排序字段， 销量：sales， 销售额：gmv，直播数：liveCount，视频数： videoCount |
| `from`      | 是    | 页码， 最大值 300                                           |

### product_related_commerce_live_list

获取指定商品在周期内关联的带货直播列表，列表信息包括：直播基础信息、商品在该直播间的销售数据。

| 参数          | 必填   | 说明                                                         |
|-------------|------|------------------------------------------------------------|
| `productId` | 是    | 商品id                                                       |
| `startTime` | 是    | 开始时间   格式：2026-01-01， 最早日期支持到3年前                           |
| `endTime`   | 是    | 结束时间  格式：2026-01-01， 最早日期支持到3年前， 开始时间和结束时间差不超过365天         |
| `keyword`   | 否    | 搜索关键词。                                                     |
| `type`      | 否    | 带货渠道：达人号 `daren`、店铺号 `shop`、品牌号 `brand`。                   |
| `sort`      | 否    | 排序字段：价格 `unitPrice`、销量 `sales`、销售额 `gmv`、开播时间 `startTime`。 |
| `mod`       | 否    | 排序方式：升序 `asc`、降序 `desc`。                                   |
| `size`      | 否    | 每页条数，最大 `50`。                                              |
| `from`      | 是    | 页码， 最大值300                                                 |

### product_related_commerce_video_list

获取指定商品在周期内关联的带货视频列表，列表信息包括：视频基础信息、商品在该视频产生的销售数据。

| 参数           | 必填    | 说明                                                                                         |
|--------------|-------|--------------------------------------------------------------------------------------------|
| `pid`        | 是     | 商品id                                                                                       |
| `cid`        | 否     | 分类 ID。                                                                                     |
| `keyword`    | 否     | 搜索关键词。                                                                                     |
| `time`       | 否     | 快捷周期：近7天 `7`、近30天 `30`、近90天 `90`。                                                          |
| `startTime`  | 否     | 自定义开始时间，格式 `yyyy-MM-dd`。                                                                   |
| `endTime`    | 否     | 自定义结束时间，格式 `yyyy-MM-dd`。                                                                   |
| `sort`       | 否     | 排序字段：销售额 `video_gmv`、销量 `video_sales`、点赞 `digg_count`、评论 `comment_count`、分享 `share_count`。 |
| `mod`        | 否     | 排序方式：升序 `asc`、降序 `desc`。                                                                   |
| `incTime`    | 否     | 视频声量每日变化筛选。                                                                                |
| `awemeType`  | 否     | 作品类型：普通视频 `video`、图文 `image`。                                                              |
| `tag`        | 否     | 业务标签；商品带货视频场景使用 `1`。                                                                       |
| `videoScene` | 否     | 发布场景：主页视频 `home`、投放视频 `ad`。                                                                |
| `from`       | 是     | 页码， 最大值 300                                                                                |

### product_top_selling_product_rank_period

获取历史周期的商品热销榜单，榜单按周期内商品销量降序取TOP商品列表，列表信息包括：商品基础信息、销售数据、近30天销量趋势。

| 参数           | 必填  | 说明                                                                                 |
|--------------|-----|------------------------------------------------------------------------------------|
| `sort`       | 是   | 排序字段（降序） 销售额：gmv 销量：sales                                                          |
| `mod`        | 否   | 排序方式：升序 `asc`、降序 `desc`。                                                           |
| `rdate`      | 是   | 查询日期  日榜:格式：yyyy-mm-dd 周榜格式：mm月dd日-mm月dd日  月榜:yyyy年mm月 年榜:示例：2026年                 |
| `periodType` | 是   | 榜单类型 日榜:day 周榜：week 月榜：month 年榜：year 本周: scrollWeek 本月: scrollMonth 本年: scrollYear |
| `price`      | 否   | 价格区间 示例100,300 中间用,隔开                                                              |
| `brand`      | 否   | 是否品牌商品 是：true 否：false                                                              |
| `cat0`       | 否   | 0级类目id                                                                             |
| `cat1`       | 否   | 1级类目id                                                                             |
| `cat2`       | 否   | 2级类目id                                                                             |
| `cat3`       | 否   | 3级类目id                                                                             |
| `cat4`       | 否   | 4级类目id                                                                             |
| `choice`     | 否   | 商品类型  直播推广：live_pro 低价引流：price_10  直播推广&低价引流：live_pro_price_10                     |
| `source`     | 否   | 商品来源编码。                                                                            |
| `sendType`   | 否   | 物流时效：小时达 `1`、明日达 `2`。                                                              |
| `from`       | 是   | 页码最小值是1 每页返回20条数据                                                                  |

### product_top_selling_live_product_rank_period

获取历史周期的直播商品热销榜单，榜单按周期内商品直播销量降序取TOP商品列表，列表信息包括：商品基础信息、销售数据、近30天直播销量趋势。

- API：`product_top_selling_live_product_rank_period`

| 参数           | 必填   | 说明                                                      |
|--------------|------|---------------------------------------------------------|
| `sort`       | 是    | 排序字段（降序） 销售额：gmv 销量：sales  销售均价：price 佣金比例：cos_ratio    |
| `rdate`      | 是    | 查询日期  日榜:格式：yyyy-mm-dd 周榜格式：mm月dd日-mm月dd日  月榜:yyyy年mm月  |
| `periodType` | 是    | 榜单类型：日榜 `0`、周榜 `1`、月榜 `2`。                              |
| `prices`     | 否    | 价格区间，单位元，例如 `100,300`。控制器参数名是 `prices`。                 |
| `cate`       | 否    | 类目id                                                    |
| `level`      | 否    | 类目层级：`0-4`。                                             |
| `ratios`     | 否    | 佣金比例区间  最大值为1                                           |
| `uidCount`   | 否    | 关联主播数区间，使用逗号分隔。                                         |
| `sendType`   | 否    | 物流时效：小时达 `1`、明日达 `2`。                                   |
| `from`       | 是    | 页码最小值是1 每页返回20条数据                                       |

### product_top_selling_video_product_rank_period

获取历史周期的视频商品热销榜单，榜单按周期内商品视频销量降序取TOP商品列表，列表信息包括：商品基础信息、销售数据、近30天视频销量趋势。

| 参数         | 必填   | 说明                                                                |
|------------|------|-------------------------------------------------------------------|
| `sort`     | 是    | 排序字段（降序） 销售额：gmv 销量：sales  销售均价：price 佣金比例：cosRatio 预估支付佣金：cosGmv |
| `date`     | 是    | 查询日期  日榜:格式：yyyy-mm-dd 周榜格式：mm月dd日-mm月dd日  月榜:yyyy年mm月            |
| `type`     | 是    | 榜单类型 日榜:day 周榜：week月榜：month                                       |
| `price`    | 否    | 价格区间单位元 示例100-300 中间用-隔开                                          |
| `cat0`     | 否    | 0级类目id                                                            |
| `cat1`     | 否    | 1级类目id                                                            |
| `cat2`     | 否    | 2级类目id                                                            |
| `cat3`     | 否    | 3级类目id                                                            |
| `cat4`     | 否    | 4级类目id                                                            |
| `cosRatio` | 否    | 佣金比例区间 0.20-0.30 最大值1                                             |
| `aweme`    | 否    | 视频筛选标记。                                                           |
| `newRank`  | 否    | 商品上新筛选；启用时固定传 `new`。                                              |
| `sendType` | 否    | 物流时效：小时达 `1`、明日达 `2`。                                             |
| `from`     | 是    | 页码最小值是1 每页返回20条数据                                                 |
