# 达人 API 参考

本文件只包含已完整满足 `ht-api` 标准能力的正式接口。API 名和摘要使用 HT API 定义，HTTP method、path 和查询参数使用当前可执行接口定义。

## API 详情

### author_library_by_custom_search_author

通过达人带货商品分类、达人视频分类、达人基础信息和达人关键数据指标多条件组合，筛选出满足条件的达人列表，支持按指定指标排序。列表信息包括：达人昵称、达人头像、达人抖音号、达人数据指标。

| 参数               | 必填   | 说明                                                                                                                                                                          |
|------------------|------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `userType`       | 否    | 用户类型筛选：直播达人 `live`、视频达人 `video`、图文达人 `imageTxt`。                                                                                                                            |
| `sortField`      | 否    | 排序字段。可用值包括综合排序 `ht_score`、粉丝 `follower_count_total`、点赞 `total_favorited`、近30天作品数 `last30DayCount`、作品数 `aweme_count`、近30天直播销售额 `live_gmv30`、近30天音浪 `live_ticket30`。          |
| `keyword`        | 否    | 搜索关键词。                                                                                                                                                                      |
| `contentLeftTag` | 否    | 所属行业 行业id  多个行业id间,隔开                                                                                                                                                       |
| `cat0`           | 否    | 一级类目 ID                                                                                                                                                                     |
| `cat1`           | 否    | 二级类目 ID。                                                                                                                                                                    |
| `cat2`           | 否    | 三级类目 ID。                                                                                                                                                                    |
| `cat3`           | 否    | 四级类目 ID。                                                                                                                                                                    |
| `cat4`           | 否    | 五级类目 ID。                                                                                                                                                                    |
| `gmvRange`       | 否    | 近 30 天 直播带货额，例:1000000,5000000。单位元                                                                                                                                          |
| `userRangeAvg`   | 否    | 平均直播场观，例:1000000,5000000。                                                                                                                                                   |
| `gpmRangeAvg`    | 否    | 平均直播GPM 区间，例:30,50。                                                                                                                                                         |
| `priceRange`     | 否    | 带货价格带，格式：最小值,最大值。单位 元                                                                                                                                                       |
| `dsrRange`       | 否    | 带货口碑，格式：最小值,最大值。示例  高  4.7,*   、中：4.2,4.7  、低： *,4.2                                                                                                                        |
| `gLevel`         | 否    | 达人带货等级筛选。示例：最小为1  最大为7    多个间,隔开                                                                                                                                            |
| `followerRange`  | 否    | 粉丝数区间，格式：最小值-最大值。单位：万                                                                                                                                                       |
| `diggRange`      | 否    | 点赞数/点赞均值区间，格式：最小值-最大值。 单位：万                                                                                                                                                 |
| `incFans`        | 否    | 涨粉数 格式：最小值,最大值                                                                                                                                                              |
| `isOpenWindow`   | 否    | 是否开通橱窗：`true`、`false`、`all`。                                                                                                                                                |
| `isEarnest`      | 否    | 个人/黄V认证：`true`、`false`、`all`。                                                                                                                                               |
| `company`        | 否    | 蓝V认证：`true`、`false`、`all`。                                                                                                                                                  |
| `customVerify`   | 否    | 认证信息关键词                                                                                                                                                                     |
| `gender`         | 否    | 性别筛选。女:2  男：1                                                                                                                                                               |
| `ageRange`       | 否    | 年龄区间，格式：最小值-最大值。                                                                                                                                                            |
| `province`       | 否    | 省份筛选。                                                                                                                                                                       |
| `region`         | 否    | 地区筛选。                                                                                                                                                                       |
| `fansGroup`      | 否    | 是否有粉丝群 有： exist  无：no_exist                                                                                                                                                 |
| `hasMcn`         | 否    | 是否有 MCN 机构：`true`、`false`、`all`。                                                                                                                                            |
| `contactWay`     | 否    | 是否有联系方式：`true`、`false`、`all`。                                                                                                                                               |
| `isLive`         | 否    | 是否有直播记录：`true`、`false`、`all`。                                                                                                                                               |
| `maxGender`      | 否    | 粉丝画像主要性别：男 `1`、女 `2`。                                                                                                                                                       |
| `maxAge`         | 否    | 粉丝年龄段                                                                                                                                                                       |
| `maxArea`        | 否    | 粉丝地区                                                                                                                                                                        |
| `maxCity`        | 否    | 粉丝城市                                                                                                                                                                        |
| `maxCg`          | 否    | 群体分布 小镇青年:3 小镇中老年:2  z世代:1 宝妈一族:5 都市白领：4  城市中产:6  新代蓝领:7 银发一族:8                                                                                                             |
| `type`           | 否    | 关键词搜索类型。nickname/authorId/uid/signature                                                                                                                                     |
| `liveType`       | 否    | 直播类型：小店自播 `shop`、品牌自播 `brand`、达人自播 `daren`、黑马 `darkHorse`、屏蔽达人 `blockUser`。                                                                                                 |
| `from`           | 是    | 页码 从1开始  最小值为1                                                                                                                                                              |

### author_basic_info

获取指定达人的基础信息。

| 参数    | 必填  | 说明     |
|-------|-----|--------|
| `uid` | 是   | 达人 UID |

示例:
```json
{
  "uid":"FQW4QohkeMLZUPknxvaddQ=="
}
```

### author_related_live_list

获取指定达人在周期内开播的直播列表，列表信息包括：直播基础信息及直播数据指标。

| 参数      | 必填 | 说明                                              |
|---------|----|-------------------------------------------------|
| `uid`   | 是  | 达人uid                                           |
| `from`  | 否  | 页码，最大值300，默认1，页大小固定10                           |
| `has`   | 否  | 直播类型：带货直播 `HAS_GOODS`、非带货直播 `NO_GOODS`。         |
| `start` | 是   | 开始时间 最早支持3年前， 示例: 2026-01-01                    |
| `end`   | 是   | 结束时间  最早支持3年前， 开始时间和结束时间差不超过30天,  示例: 2026-01-01 |
| `sort`  | 否  | 排序字段：销量 `4`、销售额 `5`、人数峰值 `6`、观看人次 `7`  开播时间(默认) |

示例:
```json
{
  "uid":"FQW4QohkeMLZUPknxvaddQ==", 
  "start": "2026-07-11",
  "end": "2025-08-11"
}
```

| `startTime` | `str` | 是 | `` | 开始时间 最早支持3年前， 示例: 2026-01-01 |
| `endTime` | `str` | 是 | `` | 结束时间  最早支持3年前， 开始时间和结束时间差不超过30天,  示例: 2026-01-01 |

示例:
```json
{
  "uid":"FQW4QohkeMLZUPknxvaddQ==",

  "endTime": "2025-08-11"
```

### author_related_video_list_video

获取指定达人在周期内发布的视频列表，列表信息包括：视频基础信息及视频数据指标。

| 参数              | 必填  | 说明                                                       |
|------------------|-----|----------------------------------------------------------|
| `uid`            | 是   | 达人 UID。                                                  |
| `from`           | 否   | 页码，取值范围 `1-300`。(默认1）                                    |
| `keyword`        | 否   | 搜索关键词。                                                   |
| `sortField`      | 否   | 排序字段：点赞 `digg`、评论 `com`、分享 `share`、销量 `sales`、销售额 `gmv`。 |
| `queryTimeStart` | 是   | 开始时间   格式：2026-01-01， 最小日期支持到3年前                         |
| `queryTimeEnd`   | 是   | 结束时间  格式：2026-01-01， 最小日期支持到3年前， 开始时间和结束时间差不超过30天        |
| `maskRemoved`    | 否   | 是否屏蔽已删除作品：`true`/`false(默认)`。                            |
| `type`           | 否   | 作品分类：带货视频 `with_fusion_goods`、非带货视频 `with_no_goods`      |
| `awemeType`      | 否   | 作品类型：图文 `image`、视频 `video`。                              |

示例：
```json
{
  "uid":"FQW4QohkeMLZUPknxvaddQ==", 
  "queryTimeStart":"2026-07-11",
  "queryTimeEnd":"2026-08-11",
  "sortField":"sales"
}
```

### author_commerce_author_rank_period

获取历史周期的直播带货达人榜单，榜单按周期内直播销售额降序取TOP达人列表，列表信息包括：达人基础信息、销售数据。

| 参数 | 必填 | 说明                                                                                      |
| --- |---- |-----------------------------------------------------------------------------------------|
| `level` | 否   | 类目层级：`0-4`。                                                                             |
| `cid`| 否 | 达人分类 示例 生活：10117                                                                              |
| `cat0` | 否  | 类目id                                                                                    |
| `rdate`| 是  | 查询日期  日榜:格式：yyyy-mm-dd 周榜格式：mm月dd日-mm月dd日  月榜:yyyy年mm月 季度榜 示例2026年Q2季度  半年榜：示例：2026年上半年 |
| `periodType`| 是  | 榜单类型 日榜:0 周榜：1  月榜：2   季度榜：4  半年榜：5                                                     |
| `userType`| 否 | 筛选条件  品牌自营:brandSelf  达人分销:daren                                                        |
