# 直播 API 参考

本文件只包含已完整满足 `ht-api` 标准能力的正式接口。API 名和摘要使用 HT API 定义，HTTP method、path 和查询参数使用当前可执行接口定义。

## API 索引

| API                                        | 摘要                                                                                |
|--------------------------------------------|-----------------------------------------------------------------------------------|
| `live_live`                                | 获取指定直播间从开播到下播，各个时间点的场观明细、直播间观众画像及弹幕热词                                             |
| `live_library_custom_search_live`          | 通过主播名称关键字、直播基础信息和直播关键数据指标多条件组合，筛选出满足条件的热门直播列表，支持按指定指标排序。列表信息包括：直播标题、直播头图、直播数据指标。  |
| `live_basic_info_audience_profile`         | 获取指定直播场次的基础信息、关键数据指标、观众画像。                                                        |
| `live_product_list`                        | 获取指定直播场次的带货商品列表。                                                                  |
| `live_top_selling_commerce_live_rank_rank` | 获取今日热销带货直播间榜单，列表包括：直播基础信息、直播销售数据。                                                 |
| `live_room_barrage_detail`                 | 获取制定直播场次的弹幕原文明细。                                                                  |

## API 详情

### live_live

获取指定直播间从开播到下播，各个时间点的场观明细、直播间观众画像及弹幕热词

| 参数       | 必填   | 说明    |
|----------|------|-------| 
| `roomId` | 是    | 直播间id |
| `uid`    | 是    | 达人uid |

### live_library_custom_search_live

通过主播名称关键字、直播基础信息和直播关键数据指标多条件组合，筛选出满足条件的热门直播列表，支持按指定指标排序。列表信息包括：直播标题、直播头图、直播数据指标。

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `sort`  | 否  | 排序字段：人数峰值 `maxUserCount`、平均在线 `avg_user_count`、直播销量 `sales`、直播销售额 `gmv`、UV价值 `uvValue`、商品数 `goodsCount`、音浪 `incTicketCount`、人均停留 `avgUserDuration`、开播时间 `startAt`、涨粉 `incFollowerCount`。 |
| `verify`  | 否  | 是否黄V认证：`true`/`false`。 |
| `blueV`  | 否  | 是否机构认证蓝V：`true`/`false`。 |
| `enterprise`  | 否  | 是否企业认证蓝V：`true`/`false`。 |
| `customVerify`  | 否  | 认证信息筛选；无认证固定传 `NOT`。 |
| `followerRange`  | 否  | 开播粉丝数区间 示例：10000,100000/   *,10000   /10000000,* |
| `cat0`  | 否  | 0级类目id |
| `cid`  | 否  | 达人分类id |
| `province`  | 否  | 省份 |
| `region`  | 否  | 城市 |
| `scoreRange`  | 否  | 口碑分  高：4.7,* 、中：4.2,4.7 、 低：4.7,* |
| `totalUser`  | 否  | 观看人次区间 示例：100000,500000/*,10000/5000000,* |
| `maxUserCount`  | 否  | 人数峰值  示例：100000,500000/*,10000/5000000,* |
| `userDuration`  | 否  | 人均停留 单位（秒） 示例： 30,60/*,10/360,* |
| `uvValue`  | 否  | uv价值 示例:2,3/*,0.5/5,* |
| `liveSales`  | 否  | 直播销量 示例：50000,100000/*,1000/00000,* |
| `liveGmv`  | 否  | 直播销售额(单位元)  示例;50000,100000/*,1000/00000,* |
| `cosRatioRange`  | 否  | 平均佣金率 示例：*,0.2/0.2,0.3/0.3,* |
| `flowRate1`  | 否  | 流量结构-短视频引流  示例：0.04,0.05 |
| `flowRate2`  | 否  | 流量结构-关注  示例：0.04,0.05 |
| `flowRate3`  | 否  | 流量结构-推荐feed  示例：0.04,0.05 |
| `flowRate4`  | 否  | 流量结构-直播广场  示例：0.04,0.05 |
| `flowRate5`  | 否  | 流量结构-搜索  示例：0.04,0.05 |
| `flowRate6`  | 否  | 流量结构-个人主页  示例：0.04,0.05 |
| `flowRate7`  | 否  | 流量结构-预估付费  示例：0.04,0.05 |
| `expRate`  | 否  | 穿透率 示例：0.1,*/0.2,* |
| `createTimes`  | 否  | 开播时间范围，开始时间最早为近两年，跨度最多90天。 |
| `type`  | 否  | 直播状态：历史直播 `history`、正在直播 `2`。 |
| `roomHasGoods`  | 否  | 是否带货直播：`true`/`false`。 |
| `roomType`  | 否  | 直播间类型，可多选：付费投流为主 `1`、自然流为主 `2`、黑马直播间 `3`、直播画面优秀 `4`、高转化直播间 `5`、日不落直播间 `6`、憋单直播间 `7`。 |
| `from`  | 是  | 页码 从1开始  （每页返回12条） |

### live_basic_info_audience_profile

获取指定直播场次的基础信息、关键数据指标及带货商品列表。

| 参数       | 必填   | 说明    |
|----------|------|-------| 
| `roomId` | 是    | 直播间id |
| `uid`    | 是    | 达人uid |

### live_product_list

获取指定直播场次的带货商品列表。

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `roomId` | `str` | 是 | `` | 直播间id |
| `uid` | `str` | 是 | `` | 达人uid |
| `brand` | `Optional[str]` | 否 | `null` | 品牌关键词。 |
| `level` | `Optional[int]` | 否 | `null` | 类目层级，例如 `1`。 |
| `from` | `Optional[int]` | 否 | `-1` | 页码；未传时控制器使用 `-1`。 |
| `size` | `Optional[int]` | 否 | `null` | 每页条数，最大 `10`。 |
| `sort` | `Optional[str]` | 否 | `null` | 排序字段：上架时间 `upTs`、下架时间 `offTs`、销量 `sales`、销售额 `gmv`、券后价 `couponPrice`、佣金 `cosFee`、讲解时间 `explainTime`、退货率 `refundRate`、访客转化率 `visRate`。 |
| `mod` | `Optional[str]` | 否 | `null` | 排序方式：降序 `DESC`、升序 `ASC`。 |

### live_top_selling_commerce_live_rank_rank

获取今日热销带货直播间榜单，列表包括：直播基础信息、直播销售数据。

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `rankCate` | `Optional[int]` | 否 | `0` | 特色主题：全部 `0`、国家补贴 `1`、抖音旗舰 `2`、玩具模型 `3`、女装 `4`、珠光宝器 `5`、个人护理 `6`、生鲜 `7`、内衣裤袜 `8`、男装 `9`、床上用品 `10`、女鞋 `11`、亲子装 `12`、彩妆香水 `13`、手机 `14`、冲饮 `15`、保健食品 `16`、大家电 `17`、零食特产 `18`、婴童尿裤 `19`、文玩藏品 `20`、茶 `21`、时尚饰品 `22`。源码名称表还声明了 `23=粮油调味`，但实际值映射缺少 `23`，不可调用。 |
| `sort` | `Optional[str]` | 否 | `null` | 排序字段（降序）：带货热度 `score`、销量 `sales`、销售额 `gmv`。 |

### live_room_barrage_detail

获取制定直播场次的弹幕原文明细。

| 参数       | 必填   | 说明          |
|----------|------|-------------|
| `roomId` | 是    | 直播间id       |
| `from`   | 是    | 页码 ， 最大值300 |
