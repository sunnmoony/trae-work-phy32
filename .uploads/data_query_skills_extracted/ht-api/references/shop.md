# 小店 API 参考

本文件只包含已完整满足 `ht-api` 标准能力的正式接口。API 名和摘要使用 HT API 定义，HTTP method、path 和查询参数使用当前可执行接口定义。

## API 索引

| API                                                            | 摘要                                                                                    |
|----------------------------------------------------------------|---------------------------------------------------------------------------------------|
| `shop_related_commerce_author_list`                            | 获取指定小店在周期内关联的带货达人列表，列表信息包含：达人基础信息、该达人归属小店的销售数据（示例：销量、销售额、关联直播数、关联视频数等）                |
| `shop_library_custom_search_shop`                              | 通过小店基础信息和小店关键数据指标多条件组合，筛选出满足条件的小店列表，支持按指定指标排序。列表信息包括(近30天)：小店名称、小店logo、小店数据指标。        |
| `shop_basic_info`                                              | 获取指定小店的基础信息。                                                                          |
| `shop_order_profile`                                           | 获取指定小店的成交/观众画像，成交画像类型包括： 性别、年龄、地区。                                                    |
| `shop_related_commerce_live_list`                              | 获取指定小店在周期内关联的带货直播列表，列表信息包括：直播基础信息、该直播间归属小店的销售数据。                                      |
| `shop_related_commerce_video_list`                             | 获取指定小店在周期内关联的带货视频列表，列表信息包括：视频基础信息、视频的销售数据。                                            |
| `shop_key_metrics_live_video_author_sales_data_period_total`   | 获取指定小店在周期内的关键数据指标，返回周期内各指标的合计值，包括小店数据、销售数据、关联达人数据、关联直播数据、关联视频数据。                      |
| `shop_key_metrics_live_video_author_sales_data_daily_detail`   |  获取指定小店在周期内的关键数据指标明细，按日返回各数据指标值，包括小店数据、销售数据、关联达人数据、关联直播数据、关联视频数据。                     |
| `shop_related_category_list`                                   | 获取指定小店在周期内动销的品类列表，列表信息包括：品类数据指标。                                                      |
| `shop_related_product_list`                                    | 获取指定小店在周期内的动销商品(包含直播/视频/商品卡)列表，列表信息包括：有商品卡动销的商品基础信息及商品数据指标。                           |
| `shop_top_selling_brand_shop_rank_period`                      | 获取历史周期的(profitType参数为brand表示品牌)小店热销榜单，榜单按周期内品牌官方小店销售额降序取TOP小店列表，列表信息包括：小店基础信息、小店销售数据。 |

## API 详情

### shop_related_commerce_author_list

获取指定小店在周期内关联的带货达人列表，列表信息包含：达人基础信息、该达人归属小店的销售数据（示例：销量、销售额、关联直播数、关联视频数等）

| 参数          | 必填   | 说明                                                                                                                         |
|-------------|------|----------------------------------------------------------------------------------------------------------------------------|
| `id`        | 是    | 店铺id                                                                                                                       |
| `time`      | 是    | 时间范围， 开始时间和结束时间用英文逗号分隔，最小时间均为当前时间对应的近3年， 开始时间和结束时间差不超过365天                                                                 |
| `fans`      | 是    | 粉丝层级，分为四档：足部、腰部、肩部、头部， 足部对应传参：10000,100000； 腰部：100000,1000000； 肩部：1000000,5000000；  头部：5000000,*。  5000000,*表示大于等于 5000000 |
| `sort`      | 是    | 排序字段，粉丝数：fans，  销量：sales， 销售额：gmv， 客单价：price， 商品数：pid                                                                      |
| `keyword`   | 是    | 搜索关键词                                                                                                                      |
| `tag`       | 是    | 达人类型， 全部达人：all， 直播达人：live， 视频达人：video                                                                                      |
| `goodsType` | 是    | 带货渠道， 品牌号：brand,  达人号：daren                                                                                                |
| `level`     | 是    | 带货类目层级                                                                                                                     |
| `cate`      | 是    | 带货类目id                                                                                                                     |
| `cat1`      | 是    | 当所选带货类目层级大于1级时该字段是所选类目对应的1级带货类目id                                                                                          |
| `from`      | 是    | 页码， 最大值300                                                                                                                 |

### shop_library_custom_search_shop

通过小店基础信息和小店关键数据指标多条件组合，筛选出满足条件的小店列表，支持按指定指标排序。列表信息包括：小店名称、小店logo、小店数据指标。

| 参数               | 必填   | 说明                                                                                                     |
|------------------|------|--------------------------------------------------------------------------------------------------------|
| `sort`           | 是    | 排序字段（降序） 销售额：gmv 销量：sales 关联直播数:liveCount 关联视频数：videoCount  关联达人数：uidCount 推广商品数：pidCount              |
| `keyword`        | 否    | 搜索关键词                                                                                                  |
| `cate`           | 否    | 筛选类目id                                                                                                 |
| `fusionShopFlag` | 否    | 是否仅筛选旗舰店：`true`/`false`。                                                                               |
| `liveSales`      | 否    | 销量区间                                                                                                   |
| `liveGmv`        | 否    | 销售额区间单位元                                                                                               |
| `liveRange`      | 否    | 关联直播场次区间                                                                                               |
| `awemeRange`     | 否    | 关联视频数区间                                                                                                |
| `podcastRange`   | 否    | 关联达人数区间                                                                                                |
| `livePidCount`   | 否    | 关联商品数区间                                                                                                |
| `province`       | 否    | 小店所在省份                                                                                                 |
| `region`         | 否    | 小店所在城市                                                                                                 |
| `brandIcon`      | 否    | 小店类型 抖音旗舰店：aweme_flagship 全球购：global_shopping 自营：Domestic_self_operated 抖音超市自营：market_day_arrived_self |
| `cosRatioRange`  | 否    | 平均佣金率区间 最大值1 最小值0                                                                                      |
| `shopBo`         | 否    | 店播为主 区间  最大值1 最小值0                                                                                     |
| `brandBo`        | 否    | 品牌自播为主 最大值1 最小值0                                                                                       |
| `darenBo`        | 否    | 达播为主 最大值1 最小值0                                                                                         |
| `liveBo`         | 否    | 直播带货为主 最大值1 最小值0                                                                                       |
| `videoBo`        | 否    | 视频带货为主 最大值1 最小值0                                                                                       |
| `cardBo`         | 否    | 商品卡带货为主 最大值1 最小值0                                                                                      |
| `from`           | 是    | 页码最小值是1 每页返回20条数据                                                                                      |

### shop_basic_info

| 参数          | 必填   | 说明    |

| `startTime` | 是    | 开始时间  |

### shop_order_profile

获取指定小店的成交/观众画像，成交画像类型包括： 性别、年龄、地区。

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- |----| --- | --- |
| `id` | `str` | 是  | `` | 店铺id |
| `startTime` | `str` | 是  | `` | 开始时间   格式：2026-01-01， 最早日期支持到3年前 |
| `endTime` | `str` | 是  | `` | 结束时间  格式：2026-01-01， 最早日期支持到3年前， 开始时间和结束时间差不超过365天 |
| `tag` | `str` | 否  | `` | shop 表示成交画像，否则表示观众画像 |

### shop_related_commerce_live_list

获取指定小店在周期内关联的带货直播列表，列表信息包括：直播基础信息、该直播间归属小店的销售数据。

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `shopId`  | 是  | 店铺id |
| `startTime`  | 是  | 开始时间   格式：2026-01-01， 最早日期支持到3年前 |
| `endTime`  | 是  | 结束时间  格式：2026-01-01， 最早日期支持到3年前， 开始时间和结束时间差不超过365天 |
| `sort`  | 是  | 排序字段， 销量：sales， 销售额：gmv， 商品数：pidCount，客单价：unitPrice  |
| `keyword`  | 是  | 搜索关键词 |
| `shopType`  | 是  | 带货渠道， 达人号：daren， 品牌号：brand |
| `level`  | 是  | 所选类目层级 |
| `cate`  | 是  | 所选类目id |
| `cat1`  | 是  | 当所选类目层级大于1级时， 该字段是所选类目对应的一级类目id |
| `from`  | 是  | 页码， 最大值 300 |

### shop_related_commerce_video_list

获取指定小店在周期内关联的带货视频列表，列表信息包括：视频基础信息、视频的销售数据。

| 参数                   | 必填   | 说明                                                 |
|----------------------|------|----------------------------------------------------| 
| `shopId`             | 是    | 店铺id                                               |
| `keyword`            | 是    | 搜索关键词                                              |
| `startTime`          | 是    | 开始时间   格式：2026-01-01， 最早日期支持到3年前                   |
| `endTime`            | 是    | 结束时间  格式：2026-01-01， 最早日期支持到3年前， 开始时间和结束时间差不超过365天 |
| `sortField`          | 是    | 排序字段， 销量：dailySales， 销售额：gmv， 点赞：digg， 评论：comment  |
| `sortMod`            | 是    | 排序方式， 固定传参：desc                                    |
| `awemeType`          | 是    | 视频类型， 普通视频：video， 图文视频：pic                         |
| `onlySelectedPeriod` | 否    | 是否只看选定周期内发布的视频：`true`/`false`。                     |
| `shopType`           | 是    | 达人类型， 达人号：daren， 品牌号：brand                         |
| `level`              | 是    | 所选的商品类目层级                                          |
| `cate`               | 是    | 所选的商品类目id                                          |
| `cat1`               | 是    | 当所选商品类目层级大于1级时， 该字段为所选商品类目对应的1级类目id                |
| `from`               | 是    | 页码，最大值300                                          |

### shop_related_category_list

获取指定小店在周期内动销的品类列表，列表信息包括：品类数据指标。

| 参数             | 必填 | 说明                                                 |
|----------------|----|----------------------------------------------------|
| `shopId`       | 是  | 店铺id                                               |
| `from`         | 是  | 页码，最大300                                           |
| `categoryType` | 是  | 类目聚合，枚举值，cat0表示一级类目、cat1表示二级类目、cat2表示细分类目          |
| `tag`          | 是  | 枚举值，all表示所有品类、card表示商品卡品类、aweme表示视频类目              |
| `startTime`    | 是  | 开始时间   格式：2026-01-01， 最早日期支持到3年前                   |
| `endTime`      | 是  | 结束时间  格式：2026-01-01， 最早日期支持到3年前， 开始时间和结束时间差不超过365天 |
| `sortField`    | 否  | 排序字段，gmv销售额(默认)，sales销量，price均价                    |

### shop_related_product_list

获取指定小店在周期内的动销商品(包含直播/视频/商品卡)列表，列表信息包括：有商品卡动销的商品基础信息及商品数据指标。

| 参数            | 必填   | 说明                                                                  |
|---------------|------|---------------------------------------------------------------------|
| `id`          | 是    | 店铺id                                                                |
| `time`        | 是    | 时间范围 示例： 2026-05-01,2026-05-31  两个时间最小值可取到3年前， 两个时间差不超过365天         |
| `sort`        | 是    | 排序字段， 销售额：gmv， 销量：dailySales， 价格：price，                             |
| `mod`         | 是    | 排序方式， 升序：asc, 降序：desc， 只有价格支持升序                                     |
| `keyword`     | 是    | 搜索关键词                                                               |
| `level`       | 是    | 所选商品类目层级                                                            |
| `cate`        | 是    | 所选商品类目                                                              |
| `cat1`        | 是    | 当所选类目层级大于1时，该字段是所选商品类目对应的1级类目                                       |
| `brandId`     | 是    | 品牌id                                                                |
| `priceRange`  | 是    | 价格范围， 示例：300,500 表示价格在300到500之间， *,50表示价格小于等于50， 1000,*表示价格大于等于1000 |
| `tag`         | 是    | 带货方式， 全部商品：all，直播商品：live， 视频商品：video，商品卡商品：card                     |
| `shopTypeTag` | 是    | 销售额渠道， 只有带货方式为全部、直播、视频时才有带货渠道。品牌自营：brand， 达人分销：daren                |
| `searchMode`  | 否    | 搜索方式：快捷搜索 `0`、精确搜索 `1`、ID 搜索 `2`。                                   |
| `sendType`    | 否    | 物流时效：小时达 `1`、明日达 `2`。                                               |
| `from`        | 是    | 页码1， 最大值300                                                         |

### shop_top_selling_brand_shop_rank_period

获取历史周期的(profitType参数为brand表示品牌)小店热销榜单，榜单按周期内品牌官方小店销售额降序取TOP小店列表，列表信息包括：小店基础信息、小店销售数据。

| 参数            | 必填   | 说明                                                                                                  |
|---------------|------|-----------------------------------------------------------------------------------------------------| 
| `sort`        | 是    | 排序字段（降序） 销售额：gmv 销量：sales                                                                           |
| `cate`        | 否    | 筛选类目id                                                                                              |
| `rdate`       | 是    | 查询日期  日榜:格式：yyyy-mm-dd 周榜格式：mm月dd日-mm月dd日  月榜:yyyy年mm月 季度榜 示例2026年Q2季度  半年榜：示例：2026年上半年 年榜:示例：2026年 |
| `periodType`  | 是    | 榜单类型 日榜:day 周榜：week 月榜：month 年榜：year 季度榜：quarter   半年榜：semi                                         |
| `tag`         | 否    | 小店类型  品牌旗舰店： flag                                                                                   |
| `flagship`    | 否    | 是否仅看黑标下的旗舰店：`true`/`false`。                                                                         |
| `brandFlag`   | 否    | 是否仅看黑标品牌：`true`/`false`。                                                                            |
| `price`       | 否    | 价格区间。                                                                                               |
| `videoOrLive` | 否    | 带货方式：只看直播 `live`、只看视频 `video`。                                                                      |
| `profitType`  | 否    | 带货渠道：品牌自营 `brand`、达人 `daren`、空表示全部。                                                                 |
| `from`        | 是    | 页码最小值是1 每页返回20条数据                                                                                   |
